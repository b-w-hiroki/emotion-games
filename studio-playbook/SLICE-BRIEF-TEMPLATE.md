## 作品公開用の素材パッケージ

複数作品を並べるホームでは、完成した短編だけを公開作品として扱う。既存の試作URLや保存データは維持し、試作を完成作と同列に掲載しない。各作品の公開前に、以下を原本・表示用データ・利用権とともに揃える。

- [ ] 作品情報：作品番号、正式題名、ひと言の紹介、ジャンルまたは感情、想定プレイ時間、個別URL、公開状態。ホームと共有時に同じ情報を使う。
- [ ] 詳細紹介文：世界観、プレイヤーがすること、体験の長さを結末のネタバレなしで伝える文章。カードのひと言とは別に用意する。
- [ ] 題字：透明背景の編集可能な原本と軽量な表示用画像。小さな作品カード、タイトル画面、共有画像で読めるか確認する。
- [ ] 作品棚の絵：作品固有の世界と操作の手掛かりが伝わる絵。主役や重要な灯りなどがスマホの狭い幅でも見切れない構図にし、代替テキストを記す。
- [ ] 詳細画面の画像：実際のプレイから選んだタイトル・操作中・場面変化などの複数枚。順番、短い説明、代替テキスト、ネタバレを避ける範囲を決め、縦持ち画面で読める書き出しを用意する。
- [ ] 共有画像：1200×630のOG画像と、題字・主役が縮小表示でも判別できる確認画像。個別URLに正しい画像と説明文を設定する。
- [ ] プレイ画面の実写資料：縦持ち390×844／360×640のタイトル、操作中、代表的な結末のスクリーンショット。掲載絵と実際の体験が食い違わないか確認する。
- [ ] 短い紹介映像を使う場合：冒頭で作品固有の操作・出来事が分かり、最後に個別URLへ誘導できる6〜12秒のクリップ。音なしでも要点が伝わるか確認する。
- [ ] 素材台帳：原本と書き出し先、寸法・比率、透過の有無、光源・画風、作成方法、利用権、更新手順を記録する。

作品棚のカード比率や配置は、実際に二作目を公開する時に作品間の見え方を比較して決める。上記は新作の量産開始を意味しない。

## 作品棚と詳細モーダルの受入条件

004の一作品ホームには詳細モーダルを先行実装した。二作目の公開時に作品ごとの情報・画像を共通形式にし、カードから各作品の詳細を開けるようにする。

- 作品カードには「すぐ遊ぶ」と「詳しく見る」を別の操作として置く。紹介を読まなくても個別URLへ進める。
- 「詳しく見る」で作品ごとの詳細モーダルを開き、複数の実画面を順に見ながら紹介文・操作の要点・想定時間を確認できる。モーダル内にも「遊ぶ」を置く。
- 画像はスワイプとボタンの両方で切り替えられ、現在位置と画像の説明が分かる。結末を先に明かさず、通信が遅い時も紹介文と開始操作を使えるようにする。
- 閉じるボタン、Esc、フォーカスの移動と復帰、背景操作の抑止、画面内スクロールを確認する。390×844と360×640のタッチ・キーボード・Chromium／WebKitで、開始と閉じる操作を実際に試す。
