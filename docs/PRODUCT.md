# Product brief / Emotion Games

## 中核
- ブランドコピー：感情を、遊ぶ。
- 作品の企画順：感じさせたい感情 → 感情の山場 → それを操作に変換 → ルール → ビジュアル・技術。
- 一回30秒〜2分、説明最小、登録不要。
- オムニバスとして世界観・エンジン・ジャンルは統一しない。

## SNSファネル
動画(6〜15秒の仮説) → 個別ゲーム直リンク → 即プレイ → スコア・結果をXに共有 → ほかのゲーム → Xフォロー。

## イベント計測 (接続後)
page_view / game_start / game_complete / game_retry / share_tap / related_game_open。GA4未設定の現在は送信しない。プライバシー・同意の必要性を確認してから導入。

## 初期KPI
作品ごとのSNSクリック・プレイ開始率・完走率・リトライ率・共有率・フォロー転換。目標値は初期30日間で実測して決定する。

## 新しい制作フロー
企画20件 → 週2〜3本の小規模試作 → 実機QA → 投稿動画＋サムネ → 個別URL公開 → Xで反応を見る → 上位作品を改良。記録は作品IDで紐付ける。

## 第4作追加（2026-10）
- 004: きえないで。感情＝切なさ・希望。風と酸素のトレードオフを長押し操作で体験。軽量Canvas描画。
- シリーズの収集数は4×5=20。以降も作品数から動的計算し、特別報酬を維持する。

## 20本一次量産（2026-10）

20本×5結末＝100結末。4種の再利用可能なゲーム型から操作を短時間で実装し、投稿映像で感情的な反応を検証する。ゲーム性の核を先に作り、二次フェーズで独自性・3D/物理・演出を個別作品へ投資する。原作童話は発想の参照とし、原文・現代の翻訳・現代挿絵は転載しない。

## AI実装能力と感情喚起を別々に検証（次段階）

実装できたことを感情が動いた証拠と扱わない。研究モード（任意の `?study=1` ）で、非誘導の感情回答・ゲーム行動・再挑戦を端末内へ記録。006は2D追跡、010は長押し揚力、014はエコー記憶、017は3場面のストーリー選択へ分岐させ、共通エンジン由来の同質化を検証する。残り12本は未差別化試作として管理。記録の解釈と研究ゲートは `docs/RESEARCH.md` 参照。
