# 「きえないで。」章ごとのゲーム性強化（縦切り品質検証）

新作は増やさず、同じ長押し・リリースでも章ごとに判断が変わる構成にする。

- 雪の路地（0–20秒）: 風の予兆と炎/息を学ぶ。
- 風のトンネル（20–45秒）: 突風が増える。風が弱い一瞬を見つけて手を離すと、一度だけ建物の陰の安全地帯へ入る。次の突風に備えて息を戻せる。
- 凍った橋（45–70秒）: 風にさらされた炎への被害が増え、かばい続けても酸素が減りやすい。1章と同じ押しっぱなしの解法が通用しない。
- 夜明け前（70–90秒）: 記憶を2つ以上集め、炎が弱ってきたら、対岸の窓がこちらを見ている伏線が出る。凪に手を離した場合のみ、既存の特別な光の逆転演出へつながる。

「絶対にバズる」とは判断しない。既存の5結末を維持し、プレイヤーの行動と演出の因果を強めるための試作。
次の品質ゲートはPlaywrightで章遷移・シェルター・橋の風・復活の予告/発火・画面キャプチャを検証し、90秒の実速度で遊んだ人間がこの差を理解できるかを確認する。
