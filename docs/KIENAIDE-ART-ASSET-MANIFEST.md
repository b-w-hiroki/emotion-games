# きえないで。｜章ごとの背景実装と制作素材台帳（v0.2）

## コンセプト
新たに作成したビジュアル案の「雪の夜の寒色 × 小さな火の精の暖色 × 町へ向かう旅」をゲーム内に反映する。**今回のSVGは静止背景の一次実装**。提示した高密度なコンセプトイラストそのものの完成素材ではなく、後続の高精細アセット制作と差し替えのためのレイヤー構造の確立である。

## 実装契約
- 360×400のCanvas座標に合わせた高解像度ベクター。背景SVGは**実行コードを含まない静的な絵**。
- 建物・遠景・雪・窓などを複数の独立グループで描き、ゲーム本体が最前面の主人公・炎・風・記憶を動的描画する。実装では各章の切り替えでクロスフェード。
- 光/表情はゲームステート（\`flame\`/\`oxygen\`/\`wind\`/\`rescue\`）に追従するCanvas表現を使い、背景から分離する。
- 素材ロード失敗時は既存の手続き型の背景にフォールバックし、真っ暗な画面にならない。
- ワイヤーフレーム/仮アイコンは完成品扱いしない。次版はキャラ表情・衣装・背景パースと陰影・発光の一貫性をモックと比較し、必要なら生成素材へ差し替える。

## 品質チェック
- 390×844/360×640のレイアウトと操作、背景ファイル読み込み、4章の描画、数値と炎の反応、全5結末、PNG結果カード。
- 不要な横スクロール、読めない色、激しい点滅は不合格。
- 人間の感情反応とSNSの動画完走は別途プレイテストが必要。CI成功だけで視覚的な魅力を実証しない。

## v1.0 — 本編 `/kienaide/` のレイヤー美術（2026-10-16）

本編は `assets/kienaide/` の分離レイヤーで描画する。原本は生成スクリプト `scripts/art/kienaide-art.mjs`
（`node scripts/art/kienaide-art.mjs` で再生成、乱数シード固定）。一覧は `assets/kienaide/manifest.json`。

| レイヤー | 内容 | 備考 |
|---|---|---|
| `chN-sky` | 空・月・星 | ほぼ動かない |
| `chN-far` | 遠景（屋根並み・トンネル出口・対岸・丘） | 視差 小 |
| `chN-mid` | 中景（家並み／アーチ／橋と氷／家への道） | 視差 中・ズームで前進感 |
| `chN-fore` | 前景（雪だまり・街灯・氷柱・枝） | 主人公の手前に重ねる |
| `chN-lights` | 窓・街灯の光源だけ | 加算合成。最終章の窓の返事に使う |
| `hero-body` | 後ろ姿の少女（炎・発光なし） | テストで暖色・グラデ発光が無いことを検査 |
| `hero-hands-hold` / `hero-hands-shield` | 支える手／かばう手 | 長押しで切替 |
| `hero-rim` | 白のリムライトマスク | 実行時に炎色で着色し、灯りの強さで不透明度を変える。炎0で消える |
| `intro-room` / `intro-lights` | 導入「最後の灯り」の暖炉の部屋 | |

- 4章で消失点（240,252）とカメラ高さ・主人公位置を統一し、構図は章ごとに作り分けた。
- 炎は画像ではなくCanvasで毎フレーム描く（大きさ・傾き・表情・ハロー）。炎0では発光・リム・足元の光すべてゼロ。
- 画面比に応じて論理幅300〜480で中央を切り出す。SVGは画面サイズごとに1回だけラスタライズしてキャッシュ。
- 読み込み失敗時は章色のグラデーションと簡易シルエットで進行を止めない。
- 検証: `node scripts/qa-kienaide-visual.mjs chromium|webkit`（章・かばう手・光の画素比較・FPS・5結末・導入）。
