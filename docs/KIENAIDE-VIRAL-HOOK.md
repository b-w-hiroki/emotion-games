# 『きえないで。』｜動画・SNSで伝わる感情の山場 v1

## 目的
バズを数字だけで捉えない。ゲーム固有の「守るためには手を放す」というジレンマを、見ただけで疑問が生じる短いシーンに変換する。**バズは仮説であって、再生回数・共有率など実測前に成功を宣言しない**。

### 1. 最後のひと押しを、あえて手放す
最終章（70〜89秒）、記憶2つ以上を回収し、炎が29%以下まで弱まり、酸素が残った状態で、風が凪いだ瞬間に長押しを離すと、目的地の窓が光を返す。

- 行動と条件が因果関係を持つ。乱数で発火せず、守り続けるより手を放したほうが助かる瞬間を作る。
- 一度のプレイで最大1回。窓・周囲の粒子・音・物語テキストを合わせる。
- 既存の5結末を増やさず、**同じ結末に至る道のりが違う**ことを価値にする。
- 体験や演出を盛りすぎて、達成した本人にしか分からない原因不明の救済にしない。

### 2. プレイヤーの結末からカードを作る
終了画面の「結末カードを保存・共有」で、Canvasから900×1200 PNGを作成。炎の場面、結末名、記憶数、特別な出来事、ゲーム直リンクを含める。

- 対応ブラウザではユーザーがシェアシートから手動で共有できる。
- 非対応ではPNGを保存する。投稿や外部送信は**自動では行わない**。
- SNSで動画を添付する場合も各作品の直リンクを使う。特別な瞬間は画面で見せ、結末をすべてネタバレしない。

### 3. 投稿映像のフック（企画案・未投稿）
| 秒数 | 見せるもの | 狙い |
|---|---|---|
| 0〜2秒 | 炎が今にも消えそう | 状況を説明なしで伝える |
| 2〜5秒 | プレイヤーがなぜか手を放す | 意外性・疑問 |
| 5〜8秒 | 向こうの窓から光が戻る | 驚き・感情の反転 |
| 8〜11秒 | 「守るために、手を放す。」＋作品名・直接リンク | 自分でも試したい |

音声なしでも伝わる明暗・ジェスチャー・状態変化を主軸とする。X動画のトリミング前に実プレイ映像から抽出し、事実と違う演出を合成しない。

## 検証指標
- **実装ゲート**：発火条件の境界と一回制限、端末操作、PNG生成、旧5結末、WebKit/iPhone表示。
- **映像ゲート**：3秒以内に炎の危機が分かるか／「なぜ離した？」という疑問が生じるかを5〜10人に見せる。
- **感情ゲート**：「安堵」「驚き」「切なさ」の本人の回答と、離す／守る行動を照合。
- **SNSゲート**：Xの動画再生完了・リポスト・直リンククリック・初回プレイ開始・リトライ率を作品単位で比較する。サンプル数が少なければ断定しない。

## 次の制作判断
主に見るのは**印象的な瞬間がゲーム体験の中で自然に発生するか**。動画だけ派手でもプレイの因果がなければ不採用。
