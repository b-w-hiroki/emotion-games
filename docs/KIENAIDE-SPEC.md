# 004「きえないで。」現行仕様

最終照合: 2026-10-19。正式版は `/kienaide/`。この文書はプレイヤーから見える現行動作の正本であり、過去の企画・監査ログは履歴として扱う。変更時の手順は [文書更新ワークフロー](./DOCUMENTATION-WORKFLOW.md)、実装の責務分担は [設計書](./KIENAIDE-DESIGN.md) を参照。

## 目的と範囲

縦持ちスマホで、消えかけた炎の精を雪の町の家まで運ぶ短編ゲーム。狙う感情は「守りたい」という緊張、手を離す怖さ、帰還時の安堵・喪失。感情が実際に生じるかは人によるプレイテストで評価する。20作品のうち004だけを完成縦切りとして扱い、他19作品の仕様は本書の対象外。

## プレイの流れ

1. タイトルで「旅をはじめる」を押す。絵画素材の読み込み完了まで開始できず、失敗時は再読込を案内する。初回のみ約19秒の導入「最後の灯り」を表示し、いつでもスキップできる。導入済みの情報は端末に保存する。
2. 雪道を自動で進む。風の予兆を見て主ボタンを長押しすると炎をかばえるが、息が減る。手を離すと息が戻るが、強風中は炎が減る。灯り・息の危険は色、点滅、文でも伝える。
3. 28秒付近で「吹雪の近道」か「軒先でひと息」を選ぶ。選択中は時計を止める。近道は到着を8秒早める代わりに8秒間風を強め、休息は到着を8秒遅らせる代わりに息を最大28ポイント戻し、4秒間風を遮る。選択時の残距離は変わらず、以後の進み方が変わる。息が満タンでも休息の風よけは働く。選択後も4章と終盤の操作が続く。
4. 三つの記憶は各8秒間だけ現れ、記憶の周りの光の輪が残り時間に合わせて縮む。絵の近くに出る「記憶にふれる」ボタン、絵へのタップ、Mキーで収集できる。取り逃すと短い物語文と控えめな音で知らせるが、常設表示は増やさない。同じ記憶は同一周回で二重収集できず、収集数は結末に影響する。
5. 到着前10秒に最後の風を迎える。予兆の後に大突風が5秒続き、1.5秒の静寂が来る。突風中はかばい、静寂で手を開くと窓が明るく応答する。炎が消えていると窓は暗い。
6. 結末専用の絵と音、到達理由を表示する。再挑戦、結末図鑑、結末カード保存・共有ができる。音・発見済み結末は周回をまたいで残る。

## 章と判断

| 章 | ゲーム内時刻 | 体験上の役割 |
| --- | --- | --- |
| 第一章 雪の路地 | 0–20秒 | 予兆、長押し、手を離して息を戻す基本を学ぶ |
| 第二章 風のトンネル | 20–45秒 | 渦風と凪を読み、弱風でかばう手を離すと建物の陰へ一度だけ入れる。手放したままの待機では発見しない。風よけは橋へ持ち越さない |
| 第三章 凍った橋 | 45–70秒 | 強風の中で手を離すと霜が蓄積し、次の強風で炎がさらに弱る。かばうと霜は和らぐが、息の消耗は増す。橋を渡ると霜は消える |
| 最終章 夜明け前 | 70秒以降 | 二つ以上の記憶と弱い炎が窓の伏線につながり、最後の風・静寂・返事を迎える |

通常の到着は90秒、近道は82秒、休息は98秒。章の開始時刻は共通で、各ルートの最終10秒を終盤に使う。画面には家までの残距離、灯り、息、記憶数、残り時間を示す。字幕は一時的に出し、常時必要な操作の案内は主ボタンに集約する。

小さな風イベントは突風・渦風・凪・誰かの灯りが一周に各一度、順番を変えて現れる。「誰かの灯り」の間は窓が風を約8割さえぎり、手を離して息を戻しても炎を守りやすい。炎への温かさも加わるが、息は通常の手放し速度で戻る。ただし吹雪の近道はその窓を通らず、選択直後の強風を受ける。近道の風が強い時は主ボタンでかばうよう案内する。

第二章の建物の陰を見つけた時は、短い物語文と控えめな音で知らせる。画面中央に四角い色面は重ねず、家までの距離は風よけ中も表示する。音を切っている時は通知音を鳴らさない。

第三章では霜が画面の端から濃くなり、蓄積して強風を受けている時は主ボタンが対処を促す。凪では息を戻し、強風ではかばって霜を和らげる。常設の数値ゲージは増やさない。

## 結末の優先順位

上から先に判定する。結末IDは保存データとの互換性を守るため変更しない。

| ID | 表示名 | 現行条件 |
| --- | --- | --- |
| `smother` | 守りすぎた。 | 息が0になる |
| `blown` | 風にさらわれた。 | 炎が0になる |
| `dawn` | おかえり。 | 生存して到着、記憶3個、到着時の炎68%以上、最後の窓が明るく応答 |
| `wish` | わすれない。 | 生存して到着、記憶3個、`dawn` の条件に届かない |
| `survive` | まだ、ここに。 | 生存して到着、記憶が3個未満 |

明るい返事は、大突風中のかばいが2.5秒以上、静寂中の手放しが0.45秒以上、炎が残っている時に成立する。片方だけならかすかな返事、どちらもなければ暗い窓。終盤で弱い炎が戻る別の「奇跡」は、記憶2個以上・炎29%以下かつ残存・息30%以上などの条件で発生し得るが、帰還の結末条件を置き換えない。

## 操作・休止・アクセシビリティ

- 主操作はタッチ／ポインター長押し。Space・Enterでもかばえる。炎をかばう操作と記憶を拾う操作は別。
- 休止メニュー、道の選択、図鑑、導入中はゲーム時計・ルールを止め、背面への入力を遮断する。休止メニューでは操作説明、音量／ミュート、図鑑、やり直し、タイトルへ戻るを提供する。進行を失う操作は確認を挟む。
- 背景タブや短い横向き表示でも進行を止め、復帰時に経過時間をまとめて進めない。音が利用できない環境でもプレイを続けられる。
- 画面読み上げ用の灯り・息メーターと危険通知を持つ。`prefers-reduced-motion` では強い動きを抑える。360×640と390×844の縦画面を回帰対象とする。

## 保存・共有・再プレイ

図鑑は五つの結末IDを端末内に保存し、重複を数えない。旧版の結末データを統合する。発見が3/5なら余韻の手紙、5/5なら称号を表示する。周回中の記憶・進行は再挑戦で初期化される。共有URLからQA専用パラメーターは除く。結末カードはPNGを準備し、利用可能なら端末の共有機能、そうでなければダウンロードを使う。共有・投稿はプレイヤーの操作でのみ起動する。
