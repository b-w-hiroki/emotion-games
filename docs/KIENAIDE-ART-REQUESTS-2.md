## 依頼文

12枚とも同じ前置きを使い、最後の「ポーズと表情」の行だけ差し替える。
**全身・同じ大きさ・足の位置を同じにする**のが大事（ゲーム内で同じ場所に差し替えるため）。

```
添付した「炎なしの少女」と、まったく同じ人物・同じ服装・同じ絵柄で描き直してください。
（黒髪、紺のフード付きコート、白〜灰色の大きなマフラー、茶色の鞄と腰の小さなランタン、白いスカート、雪のついたブーツ）
全身を、添付画像と同じ大きさ・同じ位置（足元の高さも同じ）で、画面中央に描く。
炎や炎の精は描かない。橙色の照り返しも描かない。光は左上からの青い月明かりだけ。
背景は単色の灰色。縦長 3:4。文字なし。
ポーズと表情：（下から1つ選ぶ）
```

## 組み込み先（Claude 側の作業メモ）

- P1〜P7・E1〜E5 → `paint/src/hero-*.webp` / `end-*.webp`。足元の位置で揃えて切り抜き、状態ごとに体ごと差し替える
  - 待機中に数秒おき → P1（0.15秒）、歩行中 → 通常と P2 を交互
  - 突風・大突風の予兆と最中 → P3、第三章（橋）で寒いとき → P4、息30%未満 → P5
  - 手を離した直後・凪・静寂 → P6、終盤の窓の返事・奇跡 → P7
  - 長押し中は1冊目の C（`hero-shield.png`）を優先する
  - 結末の場面 → E1〜E5（blown / smother / wish / survive / dawn）
