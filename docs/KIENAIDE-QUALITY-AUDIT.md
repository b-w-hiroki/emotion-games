# きえないで。｜完成品質監査

基準：2026-10-16、main `41e956a`（PR #37）。自動検証と人間による評価を分け、未確認を完成扱いしない。

## 判定

『きえないで。』は、薄いゲージ操作デモから約90秒の完成縦切りスライスへ移行済み。物語、操作判断、固有美術、音、5結末、収集・再挑戦、アクセシビリティ、スマホ向け表示を一つの体験として実装している。コード・自動ブラウザ・生成スクリーンショットで確認できる技術条件は充足した。

ただし、実機iPhone Safariの触感・音量と、初見プレイヤーの理解・感情・再プレイ意向は外部参加者による確認が必要であり、未完了。

## 未確認・外部テストが必要

- 実機iPhone Safariで、音の初回許可、無音切替、音量バランス、長押しの触感、セーフエリア、発熱・フレーム安定を確認する。
- ゲームを知らない参加者8〜12名で、初見理解、感情の種類と強度、結末差への関心、再プレイ理由を記録する。
- 結果が基準未達なら、説明文を増やす前に予兆・入力結果・演出タイミングを修正し、同じ手順で再測定する。

手順と判定基準は [KIENAIDE-PLAYTEST.md](./KIENAIDE-PLAYTEST.md) を正本とする。
