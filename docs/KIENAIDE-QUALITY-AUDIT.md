# きえないで。｜ブラッシュアップ全項目・完成品質監査

監査日：2026-10-19。開始点は main `e1bdafc`（PR #66）、直近の main の Verify/deploy と Chromium/WebKit QA は成功。過去のチェックボックスではなく、現行コードと操作で照合する。

## 対象と判定

今回の対象は正式版 `/kienaide/`。28項目を「今回の修正13・既存実装の継続検証12・外部確認3」に整理した。これは現行作品と既存の完成基準の監査一覧であり、考え得る追加機能すべてを完成させたという意味ではない。20本の実験候補は保持し、量産や別作品への横展開は再開しない。

「修正・回帰試験追加」はソースとテストの実装状態を指す。公開完了の判定は、以下の検証コマンド、PRの両ブラウザCI、マージ後のデプロイ、公開版の実操作確認を満たすこと。自動試験は感動・面白さや実機Safari品質の証明ではない。

```text
npm run verify
node scripts/qa-kienaide-release.mjs chromium
node scripts/qa-kienaide-release.mjs webkit
node scripts/qa-kienaide-visual.mjs chromium
node scripts/qa-kienaide-visual.mjs webkit

node scripts/qa-kienaide-release.mjs chromium https://play.birdman-studio.com

```

単体テストは74件。追加のrelease QAは図鑑・停止／復帰・分岐・導入・共有・音非対応・姿勢合成を実ブラウザで扱う。既存のvisual QAは全章・5結末・画面・FPSを扱う。CIは両者をChromiumとWebKitで実行する。

画像は `artifacts/kienaide/` の `*-title-collection.png`、`*-pause-recovery.png`、`*-ending-share-uncovered.png` と従来の全章・結末画像。動画は `clip-finale.mp4` と `clip-finale.json`。CIアーティファクトは `emotion-games-social-qa`／`kienaide-webkit-qa`。

ローカルWebKitにAudioContextがない場合、音対応のLinux CIを音声の判定に使う。ローカルrelease QAの成功を、音を含むvisual QA全体の成功と言い換えない。
