# Emotion Games｜マルチエンド・収集設計 v1

## 目的

ゲーム性の芯は「ワンアイデア」。通常の目標を理解して遊べることを優先しつつ、
**意外な操作が意外な結末を生み、プレイヤーがもう一度試したくなる**構造を重ねる。

## 共通ルール

1. 1タイトルあたり最低3種類、標準5種類の結末を用意。
2. まず通常操作で最低1種類の結末へ到達できる。正解行動以外にも報酬を与える。
3. 失敗・放置・特殊入力のどれかを隠し結末として組み込む。
4. 結末はゲームごとに端末へ保存し、結末図鑑で回収率を確認できる。
5. 未回収は「？？？」＋曖昧なヒント、回収済みはタイトル・短文を表示する。
6. 新規発見は結果画面で強調し、Xに結末名とコレクト数を共有できる。
7. 秘密操作はアクセシビリティを阻害しない。主要な結末は単純操作でも取得可能にする。

## 計測の粒度

- game_start / game_complete / game_retry
- ending_discovered（作品ID・結末ID・累計回収数）
- collection_open / share_tap（結末ID）
- Analyticsの接続は別作業。現時点では保存処理だけで外部送信は行わない。

## 追加タイトル制作契約

企画の感情 / 正規操作 / 最初の結果 / 意外な入力と結果 / 5種類の結末リスト /
UIのヒント / 収集確認 / iPhone Safari・Xアプリ内ブラウザQA / 動画の山場を1つ指定。

## Done判定

- 端末で結末発見・図鑑更新・再起動後保持を確認
- 同じ結末の再取得は二重カウントしない
- 5分以内に通常の結末を少なくとも1つ見られる
- 異常入力でJSエラー・ゲーム進行不能にならない
- 動画・画像用の結果画面がある


## 回収報酬 v2：感情の余韻

「すべての結末を回収すると強くなる」ではなく、**発見した感情を記録する**収集設計。

| 回収条件 | 報酬 | 体験 |
| --- | --- | --- |
| 新しい1結末 | 発見トークン（新発見の瞬間だけアニメーション） | 驚き／達成感 |
| 各作品3/5 | 余韻の手紙（作品固有の短文） | 意味づけ／考察 |
| 各作品5/5 | コンプリート称号と共有導線 | 誇り／共有 |
| シリーズ20/20 | EMOTION ARCHIVISTの証 | 全作回遊 |

- 取得済み結末を再度獲得しても発見演出と報酬解除は再発生させない。
- 回収数は旧来の \`emotion-endings-v1-<slug>\` に保存済みのIDから計算。スコア保存と切り離し、既存データ移行を不要にする。
- 再生を妨げる強制モーダルや広告、課金、ランキング報酬を入れない。
- 動きを減らす設定（prefers-reduced-motion）では新発見アニメーションを無効化。収集進捗は文字と数字でも確認可能。
- Xに投稿されるのはユーザーが共有ボタンを押した場合だけ。未取得の秘密を公開しない。
- 20/20の証は作品一覧で表示し、再訪時も再現される。

## QA

- 2/5 → 新しい結末で3/5 → 手紙を確認。
- 4/5 → 新しい結末で5/5 → 称号と共有導線を確認。
- 同じ結末の再入手 → 追加カウント/報酬演出が起こらない。
- 3/5と5/5を再読み込みしても保持。
- 全作品5/5 → トップで20/20の称号表示。
- iPhoneサイズ390×844 / reduced motionで表示・操作・溢れ・JSエラーを確認。

## 作品004の意図

マッチ売りの少女をそのまま再現するのではなく、「儚い炎を守りたい／守りすぎると消えてしまう」という感情の葛藤をワンボタンに変換。風と酸素の2変数を見ながら長押しとリリースを切り替える。風の動きはCanvas描画で視覚化する。炎そのものへのダブルタップで別の余韻に到達。
