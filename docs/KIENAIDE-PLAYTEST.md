# 『きえないで。』初見プレイテスト

## 目的

完成度の判定対象は「動くか」ではなく、初見で操作の因果が伝わり、狙った感情が動き、別の結末を求めて再挑戦したくなるか。参加者には狙いの感情や攻略法を事前に伝えない。

## 対象と環境

- ゲームを制作していない参加者8〜12名。うち半数以上は普段スマホゲームをあまり遊ばない人を含める。
- 可能なら実機iPhone Safariを4台条件以上、Android Chromeを2台条件以上含める。
- URLは `https://play.birdman-studio.com/kienaide/?study=1`。同じ参加者が続けて遊ぶ間はタブを閉じない。別の参加者には新しいブラウザプロファイルかプライベートウィンドウを用意し、試行記録を混ぜない。プライベートウィンドウは閉じる前にJSONを保存する。
- 最初の1回は観察者が説明や誘導をしない。音は参加者が不快でない音量にする。

## 実施用メモ

参加者には次の一文とURLだけを渡し、風・長押し・記憶・分岐・結末の攻略を先に説明しない。

> 2分ほどの短いゲームです。一度遊んで、終わったら画面の4問に答えてください。続けて遊ぶかどうかは自由です。

観察者は参加者ごとに匿名の番号（P01など）を付け、次を紙や手元のメモに残す。氏名・連絡先は記録しない。操作中に質問や助言をせず、迷いの理由はプレイ後に確認する。

| 記録項目 | 記入例・判断 |
| --- | --- |
| 環境 | P01／iPhone Safari／音ON。端末名とブラウザだけを記す |
| 初回の進行 | 完走・途中離脱、説明介入の有無、止まった場面 |
| 操作の迷い | 最初に長押し／手放しを理解した場面、記憶へのタップと道の選択で迷った場面 |
| 山場と結末 | 最後の風と静寂で何をしたか、結末の理由を本人が説明できたか |
| 自発的な再挑戦 | 観察者が促す前に2周目を始めたか、始めなかったか。意向の回答とは別に記す |
| 印象に残った瞬間 | プレイ後の本人の言葉を短く記す。回答を誘導しない |
| データ | JSON保存の成否と匿名番号に対応するファイル名。提出前に個人情報がないか確認 |

同じ端末で複数人が遊んだJSONは、端末内の試行番号だけでは参加者を分離できない。混ざったデータから実再挑戦率を計算しない。`?qa=1` 等の検査用URLは参加者に渡さない。

## 1人あたりの進行

1. 「短いゲームを一度遊び、終わった後の4問に答えてください」とだけ伝える。
2. 初回プレイを観察し、口頭の感想は操作を終えるまで求めない。
3. 結果画面の任意4問（感情、理解時点、強度、再プレイ理由）に答えてもらう。
4. 自由にもう一度遊ぶか決めてもらう。再挑戦した場合も各回の4問を記録する。
5. 最後に一問だけ「いちばん印象に残った瞬間は？」と聞き、個人を特定しないメモとして別途残す。
6. トップの検証モードからJSONを保存する。データは端末内保存で、自動送信されない。

## 合格基準

| 観点 | 縦切りスライスの合格基準 |
|---|---|
| 完走 | 初回プレイの80%以上が結末まで到達 |
| 初見理解 | 回答者の70%以上が「すぐ分かった」または「途中で分かった」。観察上、説明介入は0件 |
| 感情 | 強度平均3.5/5以上、かつ「切なさ」「緊張」「安心」の合計が回答の60%以上 |
| 再プレイ意向 | `no-retry` 以外が回答の60%以上 |
| 実再挑戦 | 参加者の40%以上が促されず2回目を開始 |
| 分岐の意味 | 2回以上遊んだ参加者の半数以上が異なる結末または記憶数に到達 |
| 実機品質 | Safari/Chromeで進行不能、音の暴発、操作不能、重大な表示欠けが0件 |

参加人数が少ないため割合は製品効果の証明ではなく、次の改善判断のためのゲートとして扱う。

## 集計

保存したJSONをリポジトリ直下で次のように集計する。

```sh
npm run study:analyze -- path/to/emotion-games-study.json
```

集計は完走率、回答数、初見理解、感情強度、再プレイ理由、結末分布に加え、『きえないで。』では記憶回収数、奇跡発生率、最低炎量、経路別の選択数・完走率・結末を表示する。新規試行では判断の内訳、記憶ID別の取得・取り逃し、火の子の返事・風よけ・奇跡、窓の応答と最後の操作時間も確認できる。途中離脱でもそれまでの発生記録を残す。旧スキーマのJSONは存在する項目だけ集計し、詳細欄の欠損を「発生しなかった」と数えない。経路不明には選択前の離脱と旧記録を含む。試行番号は端末内の順序であり、参加者数や実再挑戦率は観察メモと照合する。

## 実機チェック

- 初回タップ後に音が鳴り、音ON/OFFと音量が次回も維持される。
- 長押し、指を外へ滑らせる、通知やタブ切替後の復帰で押しっぱなしにならない。
- 390×844より狭い360×640画面でも、操作ボタン、章表示、結果、4問アンケートが操作できる。アンケートの選択肢と開閉は44px以上で、スクロールして最後の回答に届く。
- reduced-motion設定で導入と画面揺れが過剰にならない。
- 90秒通常速度を2回連続で遊び、著しい発熱、音割れ、描画停止がない。

## 記録上の注意

JSONに氏名、連絡先、自由記述などの個人情報を入れない。外部共有する前に内容を確認し、参加者の同意なしに公開しない。自動テストの結果と人間の感情評価を同じ「完了」にまとめない。
