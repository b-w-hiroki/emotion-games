# きえないで。｜ChatGPT 画像依頼台帳

正式版 `/kienaide/` に足りない絵画素材を ChatGPT（画像生成）で作るための台帳。
アート基準は `assets/kienaide-v3/`（snow-town / traveller-flame / flame-spirit）。

## 使い方

1. 各行の「添付する参照画像」を ChatGPT に添付し、「依頼文」をそのまま貼る。
2. できた画像を、ファイル名を「保存名」にしてこのセッション（Claude）へアップロードする。
3. Claude が切り抜き・分割・組み込み・QA・PR を行い、「状態」を更新する。

参照画像の場所（GitHub からダウンロード可）：

|---|---|
| 町（画風の基準） | `assets/kienaide-v3/snow-town.webp` |
| 主人公（炎あり・基準） | `assets/kienaide-v3/traveller-flame.webp` |
| 主人公（炎なし・現在使用中） | `assets/kienaide/paint/src/hero.webp` |
| 炎の精 | `assets/kienaide-v3/flame-spirit.webp` |
| 第二〜四章 | `assets/kienaide/paint/src/ch2.webp` `ch3.webp` `ch4.webp` |

## 共通ルール（どの依頼にも含まれている）

- 同じ作家・同じ世界の絵本／アニメ映画調。深い紺・藍・青紫、光は窓・街灯・炎だけ琥珀色
- 文字・ロゴ・透かしを入れない
- 「透過PNG」と書いた素材は背景を完全に透明にする（できない場合は単色の灰色背景でよい。Claude が切り抜く）

## 依頼文

### A. 暖炉の部屋（intro-room.png）

```
添付した2枚と同じ作家・同じ世界の、絵本／アニメ映画調の絵画イラストを1枚描いてください。

場面：雪の夜、小さな木造の家の中。右側に石造りの暖炉があり、火はほとんど消えて、灰の中に小さな残り火だけが橙色に光っている。左側の窓の外には雪が降り、町の明かりが消えて暗くなっている。床は木、ロッキングチェアと小さなテーブル。窓から青い月明かりが差し込む。
構図：座った目線の高さ。暖炉を画面の右寄りに大きく。暖炉の中は空けておく（あとで炎の精を重ねるため、炎の精や人物は描かない）。
色：深い紺・藍・青紫が中心。光るのは残り火だけ。静かでさみしい雰囲気。
縦長 3:4、文字なし。
```

### B1〜B5. 炎の精の表情（flame-*.png）

5枚とも同じ前置きを使い、最後の「表情」の行だけ差し替える。

```
添付した炎の精と、まったく同じキャラクター・同じ絵柄で描き直してください。
形・大きさ・色・炎の筆致は添付画像に合わせ、中央に1体だけ配置。
背景は完全に透明（透過PNG）。影や地面、文字は描かない。正方形 1024×1024。
表情：（下から1つ選ぶ）
```

| ID | 表情の行 |
|---|---|
| B1 | 穏やかで少しほほえんでいる。目はぱっちり、炎はまっすぐ上に伸びる。 |
| B2 | おびえている。目を大きく見開き、口は小さく「へ」の字。炎は風で右へ大きくなびき、少し縮こまっている。 |
| B3 | 安心している。目を細めて満足そう。炎は丸くふっくらして、穏やかな橙色。 |
| B4 | 息苦しそう。目を半分閉じ、炎は小さく暗く、色はくすんだ橙。先端が細く揺らいでいる。 |
| B5 | 希望に満ちている。目がきらきら輝き、口を開けてうれしそう。炎は明るい黄金色で、小さな火の粉がまわりに舞う。 |

### C. 炎をかばう主人公（hero-shield.png）

```
添付した「炎なしの少女」と、まったく同じ人物・同じ服装・同じ絵柄・同じ全身の構図で描き直してください。
（黒髪、紺のフード付きコート、白〜灰色の大きなマフラー、茶色の鞄と腰の小さなランタン、白いスカート、雪のついたブーツ）

変えるのは姿勢だけです：
左から強い風が吹いている。少女は少し前かがみになり、胸の前で両手のミトンを高く上げて、手のひらで小さなドームを作るように包み込んでいる（中は空っぽ。炎は描かない）。肩とマフラーで風をさえぎるように、体を少し左に向ける。
炎の光・橙色の照り返しは一切描かない。光は左上からの青い月明かりだけ。
背景は単色の灰色。縦長 3:4。文字なし。
```

```
人物・炎・文字は描かない。縦長 3:4。
内容：（下から1つ選ぶ）
```
